# i-love-game-app

🎮 Game Catalog App
A small React application where users can browse games, view details, and post comments on each game.

✨ Features
- View all games
- View details for a selected game
- See comments for each game
- Logged‑in users can add comments

Tech Stack
- React + Vite
- React Router
- Bootstrap 5 (via CDN)
- Plain CSS
- REST API server
